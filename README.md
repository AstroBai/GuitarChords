# Guitar Chords
A website for enquiring about guitar chords, built with Python and Pyodide.

Address: https://astrobai.github.io/GuitarChords/

## Features
- Categorised by root-note string (which string carries the chord root).
- You can hear the chord by clicking.
- Chord-progression reference with common patterns and famous songs.
- Transpose progressions to any key, with optional capo shapes.
- Chord fingerings are generated as compact diagrams; open the full browser for all shapes.
- Song progressions are simplified harmonic references with cited sources.
